## 先说人话

我是 CAIUS.，主业写 Java 后端，Spring Boot 那一套。偶尔被拉去写前端，于是又染上了 TypeScript 和 GraphQL。日常在终端里待的时间比在 IDE 里长，喜欢把中间件拆开看它到底怎么转，最烦文档里那句「按如下配置即可」——配完报错，文档不告诉你为什么。

这个站 2021 年 1 月开张，第一篇是 Docker 安装笔记，写得挺糙，现在还留着没删，算是个纪念。2022 年之后更新越来越少，2023 年 11 月推了最后一次构建就彻底停了。原因不复杂：换工作、图床挂了、主题升级把配置搞崩了，懒得修。2026 年重新捡起来，顺手把源码重建了一遍，图全部本地化，主题自己手写，不再依赖任何外部图床。

## 这里写什么

- **Java 开发**：JDK 新特性、JVM 排障、Spring Boot 升级、并发。基本都是线上或压测里真遇到的问题。
- **全栈开发**：TypeScript、Apollo Server、GraphQL Schema、前后端类型怎么共享。有个在线书店的 GraphQL API 我改了好几版，踩的坑够写一阵。
- **中间件**：Kafka、Redis、MySQL、Elasticsearch、Docker。偏向「出事了怎么查」而不是「怎么安装」。
- **AI 工具**：几款编码助手放同一个需求下对比，不吹不黑，把生成得不对的地方贴出来。
- **大模型**：RAG、Agent、MCP、推理成本。更关心工程落地，不聊参数规模。
- **月度报告**：这个月写了什么、线上炸了什么、读了什么、下个月想干嘛。

## 我对自己文章的三条要求

1. 代码能复制下来跑，依赖版本和完整 import 都给全。
2. 报错信息贴原文，包括那些看起来很蠢的低级错误。
3. 不写「综上所述」「值得注意的是」，也不写「本文将深入探讨」。

做不到的时候宁可先不发。另外所有面向用户的文案我都写中文，代码标识符保持英文，这是习惯问题，不是规范之争。

## 环境

Mac / JDK 21 / Docker Desktop / VS Code / zsh。示例代码默认 Linux 或 macOS，Windows 的差异会单独标出来。文章里出现的压测数字都是我本机或测试环境跑的，别拿去当生产基准。
