- 旧仓库里 **9 篇**文章，`<article id="article-container">` 全部还原成 Markdown，28 个 highlight.js 代码块去掉行号 gutter 后转回围栏代码块。

- `canonical` 从 `http://example.com/index.html` 改成了真实地址。这个配置错了三年，搜索引擎一直在收一个不存在的域名。

构建时间：`hexo generate` 冷启动 1.9s，12 篇文章共 18 个 HTML 页面。

## 踩坑记录

**一、`hexo-cli` 不认这个项目。** 装完 `hexo` + `hexo-renderer-ejs`，跑 `npx hexo generate`，只打印 Usage，什么都没生成。翻了 `hexo-cli/dist/find_pkg.js` 才明白，它是靠 `package.json` 里的 `hexo` 对象字段判断当前目录是不是 Hexo 项目的：

```json
{
  "hexo": { "version": "7.3.0" }
}
```

加上就好了。这个字段 `hexo init` 会自动生成，我手工搭目录时漏了。

**二、Hexo 7 不再自带 markdown 渲染器和页面生成器。** 第一次构建只吐出 `about/index.md` 原文件，没有 HTML，也没有首页和归档。补装 `hexo-renderer-marked`、`hexo-generator-index/archive/category/tag` 之后才正常。空站（0 篇文章）不会生成 `index.html`，这个也让我以为模板写错了，白查了二十分钟。

**三、高亮类名没有 `hljs-` 前缀。** Hexo 内置 highlight.js 输出的是 `<span class="keyword">`，不是 `<span class="hljs-keyword">`。我按官网那套写 CSS，代码块一片白，两套选择器都写了一份才算完。

**四、搜图不如画图。** 一开始想试着从 Wayback Machine 捞回 2021 年的截图，捞了两张发现分辨率糊得没法看，而且那些图本来也只是官方文档的截图。换成自己画 SVG 反而更快，顺便把内容校正了，比如 Kafka 架构图现在画的是 KRaft，不是 ZooKeeper。

## 顺手写的坏链检测

改完怕还有漏网之鱼，加了段脚本扫 Markdown 里的图片引用，确认文件都在本地：

```python
#!/usr/bin/env python3
"""扫 source/_posts 下的图片引用，外链和不存在的文件都报出来。"""
from pathlib import Path
import re

root = Path("source").resolve()
posts = root / "_posts"
pat = re.compile(r"!\[[^\]]*\]\(([^)]+)\)")

for p in sorted(posts.glob("*.md")):
    for target in pat.findall(p.read_text(encoding="utf-8")):
        if target.startswith(("http://", "https://")):
            print(f"外链图片  {p.name}: {target}")
            continue
        local = (root / target.lstrip("/")).resolve()
        if not local.exists():
            print(f"文件缺失  {p.name}: {target}")
print("done")
```

跑完是干净的。这条我打算塞进 CI，以后每次 push 都过一遍——这次是手动扫的，哪天真挂了图床，得记得再跑一遍。
